Attendance Processor V5.1

Architected, tested, and maintained by Utkarsh for Sanskar Valley Higher Secondary Public School.

Built to replace rigid, outdated legacy software with a high-performance, flexible desktop platform (developed with AI-assistance).

📖 Comprehensive User Guide

1. Importing Attendance Data

You no longer need to format Excel files manually. The system features a smart parser. Simply drag and drop your raw .xls or .xlsx attendance sheets exported from your biometric machine directly onto the application window, or click the **Import** button. The engine will parse the raw IN/OUT punches and automatically organize them into the database.

2. Managing Employees & Custom Schedules

By default, all employees use the global check-in/out times defined in the General Settings. However, school environments require flexibility.

  • Click the Employees button in the left sidebar to open the Staff Directory.
  • Click Edit next to an employee.
  • You can set their precise Monthly Base Salary (₹), assign an Override Name if the biometric machine spelled it wrong, and most importantly, define a Custom Arrival and Custom Departure time.
  • Once saved, the system will *permanently* evaluate this specific employee's attendance, tardiness, and salary based strictly on their custom schedule instead of the global defaults.
3. The Minute-Rate Salary Engine

This application uses a highly advanced mathematical engine designed to eliminate time-fraud automatically. You do not need to do any math.

  • Click Salary Report in the right-hand sidebar.
  • The system instantly calculates a precise Per-Minute Wage for each employee based on their required monthly working hours.
  • If an employee clocks in *before* their scheduled shift, or clocks out *after* their shift ends, those extra minutes are **strictly truncated and ignored**. They are only paid for valid time worked within their authorized schedule.
  • Paid Leave Bonus: If an employee takes one or more absent days during the month, the engine automatically grants them exactly one full day's worth of minute credits as a paid leave bonus. (This caps at 1 day per month).
4. Reports & Visual Filtering (No SQL Required)

The right sidebar contains pre-built Shortcut Macros like **Late Arrivals**, **Early Leavers**, and **Absentees**. Clicking these will instantly generate the relevant list.

To create your own report without knowing code:

  • Click the ＋ Custom button.
  • Use the dropdown menus to build a rule (e.g., Status -> equals -> HALF_DAY).
  • Add as many rules as you want by clicking ＋ Add Filter.
  • Click Run. The system will build the database query for you automatically and display the results. You can export any generated report to PDF or CSV using the buttons at the bottom right.
5. For Power Users (Raw SQL)

If you know SQL, you have unlimited power. Click Edit SQL to reveal the raw code editor. You can write any SELECT query against the attendance_raw and employee_salary tables, utilize SQLite date functions, and execute complex aggregations. Your query log is saved securely in the Settings tab.

Designed for flexibility, built for performance.
